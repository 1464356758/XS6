# CH005 章后记忆

【CH005，接D1夜土图，主段D2晨至入夜】顾没替陆补未知石背；陆当夜不再催气。次晨向方洪说“对不住”，提自己听见回水仍叫其向前，方因疼一夜没睡拒绝听。方右腕比昨夜肿，仍托臂、右肩护着，握持受限；指高路、叫带短杖可以，不能搬梁。夜里用左手挪陆湿衣、添柴、问何时过人，不等于原谅，未确诊骨伤也未痊愈。

顾在灯坪后废浅槽先放极细地气，陆清入口出口、压楔，用固息避开两气相撞，送气托草叶；非离地御物。第三口未尽被叫松，小指半白、冷麻；顾自身离石留不住，暂称陆的现象“留气”，来因未知。陆歇小半时辰、吃半块分来的饼，指暖才走；仍三层，丹田气力虚，旧掌伤、胸腹用力疼，无新药。生火青年自报名李满，叫阿满，普通镇人，背顾工具箱，老人从檐下另取长杆；不是CH004丢在桥下的原杆。

近岸取木者一人到坪找两名帮手，说昨日料已卸半山草棚、同伴看料，今晨去取余料；并非陆派去，更没过桥。顾、陆、阿满先实查桥背，拓出一片折纹，未修铜片或踏桥板，去向未知。后在近岸草棚当面见原两人加两帮手、木车与板。窄坎下白气顶泥，先退干石；顾压旧口，陆亲手清通数尺至无人空沟的短槽，阿满备木塞铜钉。陆只接旧口，顾移到新出口亮起后，陆在第三口未尽时主动放；阿满第二锤偏，踢正木片后落塞。气稳定后才让四人过，不是三息内运四人。

车轮脱、车倾、一块宽板跌沟裂开，未追取。四人两趟拿回其余板与细木；顾撤掌后短槽仍自行通气，潮向若再变须再看，不意味桥通或所有路稳定。七人共同返坪。陆手麻、拿不稳、绊枝，余路不催护息；夜里聚护息仅一点微光即散。顾旧伤疲劳、背更弯；阿满也险被木带脚，非无错跟班。

归程白石霜下露半笔旧纹，与桥背折法相近，顾只说明日再看；夜将实际拓片及白石摹样交陆，用陆自有旧刀压住，未知去向均留白。纸、刀不具神异。母以油坊缸底残浑油、自搓棉芯在缺嘴碟点坡口灯；归来七人后端入屋。丁木匠左踝仍架草卷，坐矮墩刨木，众人补西窗门缝，真实挡风；母让陆换包中薄衣，青衣搭顾新取杆烘。母问明日还学，陆答学，她靠补窗坐睡，未与陆谈清退舟失药的难过。

【未结】CH003灯坪最多至D3午后仍是条件估计，三千余居民未全体迁走；局部护路不延长总阵寿命。CH004旧桥仍不能过，白石与桥背关系、下一落脚点未知。CH001周含章、杜禾仍在外，远讯及十日接应无本章新核实；退令、CH002青息丸用尽、CH003弃屋断支均保留，不能用新线索取消损失。
