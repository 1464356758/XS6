# CH008《河那边有人》章后记忆

D4晨承CH007练柴皮至当日暮。陆坐小半时辰点着一片，顾本次亲见；指木后休歇、吃饼，半上午再练。母与实探男人已取水返场，自述认得浅泉灌筒法，未失踪。陆能点干燃物、离手自然烧，临急仍失手、不会御火或御物，仍炼气三层。阿满及姐姐、一家三口无新回报，不能自动归队。

方想实看如何带孩子走，右腕夹衣襟仍伤而主动同行；顾留石场，丁左踝未好。陆带旧刀短杖、水饼、少量干枝松针。二人沿泉路上方进深松，入一道石脊洞，顶有透光缝、地有低坎与暗红温石。两只小臂长灰鳞蜥逐燃枝，不追杖；陆先误以火驱，蜥咬火枝、爪划鞋外皮，袜脚未伤；方右腕碰壁疼，没因此恢复或变能抬重。陆点火失手，改将新枝松针挨旧烬点燃、扔入无草沙窝引离，拾杖护方出洞。未借地气、未杀兽、无兽药战利品。休水歇气后再走。

石场沿路五六里后实到旧桥上游东岸石亭，亭下十来级阶，顶塌半边、台上干。下游远见旧桥石墩和黑线，没再次踏桥。亭有刻叶纹残铜匣和半个声字，陆猜能传话，少量护息试无反应，内是空窝、断铜片、虫壳。他不知原装什么，未修未拆带未发讯。顾尚未见实物，不得让周含章自动收到话。

方先发现对岸持火长杆的人。陆以亭中干叶枯藤裹枝，歇水吃饼后点燃，挥火得到回应。陆方喊过回石镇、孩子、伤腿，是否全送达未核；听清对方“别走桥”“也没船”“上头石牙滩”。所谓等字听不准，没约定时辰、救援或可渡；也没船只指此人自报，非全西岸调查。对岸未听清是否山门接应，身份姓名不明；陆喊名字，对方似未听清，勿让他下章直接认陆。那火随后往上游移，二人没渡河。

陆想继续看，方独要返家；陆踩灭燃枝跟回。返洞不点火，灰蜥伏暖石未追，习性未全证，不等于整队可安全过；低坎、洞顶要让肩上孩子下来，架杆翻送尚未实试，须回问丁的办法，别抬伤者当探路。合作更近但方仍疼、未说原谅。

日偏后二人循原路返石场；陆小腿疲、膝旧擦伤牵，手背焦叶烫红、指颤，鞋帮裂口由母接看，未写补好。他向母说河那边有人应，母给水；未写把残匣与喊话完整转述给顾。上游石牙滩的近岸路、渡具与西岸去回柳岭仍待实查；D10接应承诺不等于船已到，未核全镇迁出或平台发布签约。
