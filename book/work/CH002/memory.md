# CH002 章后记忆

【CH002，D0傍晚至入夜】母子从旧屋去镇东约二里的灯坪，何素娘灭灶火、落锁，仍留着炉上水壶；她是否愿永久弃家未谈。她与熟识妇人挪草，原行李、蓝布包、被褥及新鞋随至灯坪，锅与针线笸箩仍在家。陆松原右臂冷麻未好，途中再擦破右掌根；救援时左指缝扎了木刺。救后换干中衣、裹被，青衣湿透且右袖被刀扯裂，下身亦湿冷，气力不足、运气腹内疼，未破炼气三层。

丁木匠为带半扇门板挡风而落后，滑倒后被歪木案压住左腿，妻子上坡求助。陆松先叫青年找顾槐，再带旧阵刀与唯一青息丸下坡，包留母亲处。方洪刚把妻儿送上来，借席绳与扁担同行，没有接受长期听命。两人救出丁，妻亦参与递绳、提衣及扶腿；丁左踝肿痛，鞋被剪开，伤重程度未诊定，妻在旁。普通大獾形山兽从两榆破口入镇，未杀死，最后在丁屋内撞击；不能记成全街已清兽。

陆松本次刮泥压楔才调通丁宅门边石槽；此前只清过界石炭印，不能倒填成早懂整套阵。危急时冷气入胸，他将未立即散掉的一团气送回掌下，门外起光挡兽，仅约三息；随后光灭、气乱、腿软倒地。他尚不知完整规则，未主动复现。丁替他取瓶拔塞，陆吞掉唯一青息丸才勉强续行；无第二颗、无免费疗愈或永久增功。空瓶塞回衣袋，返坡换衣时由母亲收进包。旧刀收回腰侧；扁担丢在丁屋且头被咬缺，方洪收回陆腰上一段席绳，另一段留丁屋。

【知情与情绪】方洪亲见光与服药，不等于知道药为冲关准备或施术原理；他回妻儿身边，只问回绳。何素娘见空瓶知道药已用，替儿换衣、擦伤，没有说破登舟和冲关的担心。陆松想等她发问，对旁人问青牌仍答得硬；救人成功没有消掉失落。丁夫妻相见、孩子贴父亲、热汤和添柴是真实安顿，灯坪尚非长期安全处。

顾槐从钟亭来，持回压在铜盘下的黄纸，陆松当面确认消息终于到人；焦纸鹤仍无后续确证。他听陆讲抬阵石、留铜钉及镇阵退光，见手麻、听冷气未散的自述，叫他今夜别再碰阵、不要催气，随后去坡沿。没有断言尚撑三日、许十日安全或收陆为徒。周含章、杜禾仍随舟在外；CH001十日后陆路接应仅为原承诺，未核兑现。下一章先接这夜疲倦与人事，再由新实查推进，不能把未来弃街当成本章已同意。
