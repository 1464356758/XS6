# CH001写前方案

读者关心：等了三年才拿到上船资格的陆松，能否带上母亲；若不能，他是否真舍得放弃。真正阻碍是宗门优先带走门人的既定选择与即将关闭的风窗，不能用扔一只包就解决，也不能把领队写成纯恶人。

选择A的母子与新鞋入口；另一走法是先写拆阵异常，已在openings.md实写比较。采用plan方法卡A，把资格的后果放在母亲收包、避开儿子目光和鞋子这些当下动作里，不复述检测、隐瞒天赋、入学的参考剧情。

本章先让陆松努力争取，甚至真想先走；他在搬阵石时见到能亲手辨识的异常，告知后得到有限应对而非所有人犯蠢。他仍不能知道镇阵只剩三日，最终退回登舟令、护母下山。回镇实查后看见保护层已有缺口，先把母亲往灯坪转移。退席位是实失，母亲的担忧与儿子的失落不当场清零。

参考：复用既有精读，本轮实际回读XS-KU固定提交f978c6d81eabe84267debcbd7499c89d4c9abc2c，《云灵仙路》单元3原物理行8—10（规范136—204），问题是资格结果如何由父母动作承接。不冒称新增整本阅读。前五章已有整体设计，本章没有旧冻结正文。
