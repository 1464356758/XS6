# CH006《山壁上的路》章后记忆

D3天亮前至午后。灯碟烧尽，油坊内侧窗板结霜，坪地外沿余气继续退；没有延长CH003“好的话至D3午后”的条件估计。陆睡食、行固息诀后部分恢复，仍炼气三层。白石边清理局部凿口，留气第一口吐出后即松，见下一小级石阶，冷麻后歇缓；不是开图、造路、御物或突破。

顾、陆、李满割藤、试踩，发现白石背后真实旧阶与山壁横路。凸岩侧身的窄段外落数丈，下方仍是原近岸道，未渡锁烟渡。横路尽头旧石场离灯坪绕行四里多，有石胚、楔眼、干雨沟、避风凹壁，无屋无井。西向窄径只看至第一转弯，远路不明。三人试箱后返坪，仍不等于伤者已能过。

方因CH004伤腕不信一句有路，要求陆带母先走；母自己答应，穿新鞋、带锅被水与针线。她同样怕窄岩，叫儿别喊，侧肩后亲自过了，石场铺被接丁。陆往返接人；丁当场参与竹架设计，两普通人抬，顾留坪引路。方妻用木卷和牵扶带儿过岩，方只用左手、左脚。

丁左踝怕痛，吊脚挡住转位，惊惧抓陆领口；停稳杆后，方左脚抵竹底、陆以短杖供丁握稳，解吊脚先转过岩再吊好，众人合力过关。未借气托人或超息。陆领口扯裂、膝头擦伤、疲累，母在末尾拿针补衣；右腕仍肿的方拒绝陆扶，协力不是原谅。阿满参与认路、清藤和抬后杆，不是只听命报喜。

眼前二十来人实际抵石场，母子、丁夫妻、方家都在；不是三千人全迁。顾后到，告陆坪上又走两拨，有人找镇北亲眷、两名运木人在白石岔口接引；具体去向与人数未核。顾告外排架脚冻住，不可返取物，这句仅陆在近旁听，旁人未自动知情。

陆、顾和眼前人实见对崖泉水逆山而上。顾解释底下气托水、叮嘱别近水，不知道上源和通路。陆重燃靠自己修行登高的愿望，掌光仍不能托尘。热水、存粮及夜宿后续须实找；不能将对崖泉自动当饮水。麻纸、旧刀、短杖、锅、木箱仍在；新竹架来自当场拆旧草架。周含章无新出场或传讯，CH001十日接应未兑现。目标平台按作者自报改塔读，未核投稿后台或签约，不登记章节发布。
